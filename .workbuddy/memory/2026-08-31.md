## 换装小游戏构思（v1 方案讨论）

**用户需求**：转场之后做一个换装小游戏—— 自己设计的角色 + 头顶卡片 + 点击换装 + 通关弹履历。

**她贴了一张图**：别人 vibe coding 的提示词（"小动物单词超市"），让 AI 把模糊想法补完。她想理解这种"半成品合作"的 prompt 套路，套用到自己的游戏。

**拆解别人 prompt 套路（已教）**：6 格填空模板
- 游戏方向 / 目标玩家 / 适配设备 / 核心玩法 / 想达到的效果 / "麻烦你补完"
- 最后一句是关键——"我知道我说不全，剩下的你看着办"

**套到换装小游戏上**：用户的信息已经基本够用，第 5 格（想达到的效果）= 让面试官 30 秒内记住她——这是灵魂。

**三个拍板选择（用户已选）**：
1. 角色图层 → 还没画，**先用占位角色快速验证流程**
2. 技术栈 → 让 AI 推荐 → 我推**继续纯 HTML**（已熟，够用，不上 React）
3. 履历呈现 → **弹窗 + 5 个气泡混搭**（导航+详情，跟门面页 v5 同款逻辑）

**推荐的 4 步走路线**：
① 占位 SVG 角色 + 5 张卡片摆位
② 卡片浮到头顶（带动画）
③ 点击换装（CSS opacity + transform）
④ 通关弹履历（沿用 v5 弹浮层）

**【2026-08-31 再晚·风格已定 + 半身改全身】**：用户生图后发现"只有半身没有全身"，明确要**全身**；风格定为 **Lolita 罗马卷 二次元少女**（洛丽塔洋装 + 金色罗马卷发 + 二次元/anime 画风）。全身意味着换装范围从"胸前/领口"扩大到整身（裙摆、鞋、配饰都能换），但姿势对齐要求更高（手、脚、裙摆都要对齐）。全身人像要用竖版画幅（MJ 用 `--ar 2:3`），否则裁脚。

**已教她的核心方法论**：
1. **换装 = 三层分开生成**：背景（独立大图）+ 角色底模（固定姿势、透明底）+ 衣服图层（透明底、必须和底模姿势重合）。三层叠起来，不能一次生成整图。
2. **命门 = 姿势对齐**：衣服和底模姿势对不上就错位。解法是先定底模、后出衣服。
3. **两条实现路线**：① 整图切换（同一 prompt 只换服装词生成 5 张完整角色，最简单，先跑通）；② 叠图层（图生图/局部重绘只改衣服区，姿势天然对齐，最专业）。折中：用底模做参考图图生图出 5 套。
4. **底模提示词铁律**：`正面朝向镜头` + `双手自然垂放` + `全身站姿` + `纯白色背景` + `无背景元素`——这几个词决定"姿势能对齐 + 以后能抠图"。（"半身到腰"已改为"全身站姿"，换装范围更大）

## 【2026-08-31 晚·关键反馈】底模撞车奇迹暖暖

**诊断：抄袭感的来源 = 多个元素撞一起**（不是单一元素）：
| 元素 | 为什么撞暖暖 |
| --- | --- |
| 基础白裙 + 白蝴蝶结 | 暖暖系列的"日常皮肤"就是这套 |
| 白袜 + 玛丽珍 | Lolita 圈基础款，也是暖暖标志 |
| 正面全身 + 双手自然垂 | 暖暖就是凭"角色立绘"起家的，这姿势太标志性 |
| 治愈甜美调性 | 暖暖就是这个调性的代表 |

**核心问题（赛道判断）**："罗马卷少女 × 二次元 × 治愈甜美"这个组合**默认就在暖暖赛道里**。光换华丽点的裙子没用——暖暖系列本身就是华丽风，光改色加大眼睛都是"暖暖的某个皮肤"。

**姿势不需改**：全身正面站姿是 nano banana 局部换装姿势对齐的**技术需要**，不是抄袭来源。

**给用户的破局方向（待她选）**：
- **A. 留罗马卷但放弃甜美** → 复古画家/学院/宫廷哥特（罗马卷本是欧洲贵族发式，复古很搭），配色走冷/暗（黑、银、深紫、酒红）
