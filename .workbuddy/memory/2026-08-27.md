## 第十二轮：用户反馈"不是一页滚动，直接往下翻滚了"，定位到 sticky 失效的 CSS 坑

- 用户反馈 CSS 版"不是一页滚动，直接往下翻滚了"——即画面没钉住、跟着滚轮往下翻到第二屏了。
- 【根因·重要坑】我在 `html, body` 上写了 `overflow-x: hidden`，这个属性会**偷偷把 body 变成滚动容器**，导致 `position: sticky`（钉屏）失效，画面跟着滚走。这正是"直接往下翻滚"的原因。
- 【解法·可复用】把 `overflow-x: hidden` 改成 `overflow-x: clip`——`clip` 一样能防横向溢出，但**不会创建滚动容器**，sticky 就能正常钉住。这是"想横向防溢出 + 又要 sticky 钉屏"的标准解法，以后凡是用 sticky 做钉屏滚动，一律用 `clip` 别用 `hidden`。
- 顺带两个优化：①删掉了"第二屏"（用户要的是纯单屏滚动、不要往下翻页）；②滚动轨道从 300vh 拉长到 400vh（推近更沉浸）；③滚动进度套了 `easeInOutCubic` 缓动（镜头慢-快-慢，更有电影感）。
- 【待办】等用户看钉屏版效果 → 满意就保留；若滚动节奏/推近幅度/窗口收窄速度还要调，微调参数即可。
