# 2026-08-26 工作日志

## 鼠标逐帧变幻：从"切幕"改成"滚轮逐帧翻 + 纯画面"

### 需求演进
- 用户问"这种能做成鼠标一帧一帧变幻吗" → 讲了 scrub（擦帧）原理：视频=一串照片，鼠标位置=视频进度，鼠标停哪帧就定格哪帧。
- 用一张 SVG 示意"鼠标 ↔ 帧"映射关系。
- 关键引导：跟用户说实话——直接 video.currentTime 跳秒在 2K 大视频上会卡顿不跟手；要丝滑得"把视频抽成一串静态图"。
- 用户最终选：**滚轮逐帧翻（不是左右滑）+ 纯画面（先不要文案弹窗）**。

### 技术实现
- 环境：没有 ffmpeg，但有 cv2（opencv 5.0.0）。用 cv2 抽帧，写了 `pv-site/extract_frames.py`（可复用，换新视频重跑）。
- 视频真实参数：**24fps / 362 帧 / 15.08s**（之前记 30fps 是错的，已纠正）。
- 抽帧：TARGET_FPS=10 → step=round(24/10)=2 → 实际 12fps，抽出 **181 张** `public/frames/frame-000.jpg ~ frame-180.jpg`，1920 宽、jpg q82，共 46MB。
- `App.jsx` 重写：预加载 181 张（new Image 缓存）→ 单 `<img>` 换 src → wheel 累积 deltaY、阈值 100 翻一帧（往下=前进，往上=后退），`passive:false` + preventDefault。
- `index.css` 重写为纯画面版：`.frame-img`(object-fit:cover) + 右下角帧号 HUD + 加载进度条。
- 【注意】逐帧翻是静态图切换，天然无声音（已跟用户说清：声音和逐帧是打架的）。

### 待办 / 后续
- 用户会换"更精细的 PV"来替换，替换时重跑 extract_frames.py 重新抽帧。
- 【已调】用户反馈"太细了" → 滚轮一格从翻 1 帧改为翻 3 帧，再反馈"还是有点细" → 提到 STEP=5（181帧≈36格滚完）。��感调节就两个数：`THRESHOLD=100`（滚轮一格累积量）+ `STEP`（每格翻几帧），随时可改。
- 46MB 抽帧图片本地 dev server 秒加载；正式部署前要压缩（降质量/降宽度/减帧数）。

### 【重要转折·技术选型判断】擦帧被否，回到切幕
- 用户看完擦帧手感后自己判断"这个视频不适合这样拆"——这个直觉是对的，是内容创作者的节奏判断。
- 原理（教用户的分辨方法）：**擦帧(scrub)的爽感来自"视频是一条连贯时间线"，像握倒带旋钮**。只适合「连贯运动」镜头（产品 360°转、一镜到底动作、无缝循环）。
- 用户的视频是「分镜剪辑」：4 镜头硬切（站姿→拔刀→吹泡泡→结尾），镜头间无过渡态，擦到交界会"啪"跳帧，顺滑不起来。
- 结论：**分镜视频天生适合「切幕」**（滚轮切 4 段、每段播到定格、配文案弹窗），不适合擦帧。
- 用户确认选「回到切幕」。App.jsx + index.css 从逐帧版改回切幕版：`/pv.mp4` 全屏 + goTo 淡出→跳秒→淡入→播到 videoEnd 定格 + 文案(左下)+导航(右上)+点击开始遮罩(带声音)+弹窗。scenes.js 数据没动直接复用。
- 【可复用判断口诀，记牢】以后用户/任何人拿"一段视频"问"能做擦帧吗"，先问一句：**这视频是「连贯运动」还是「分镜剪辑」？** 连贯→擦帧；分镜→切幕。别一上来就抽帧。

### 【风格方向已定·重要】作品集整体走「暗色高级感」
- 用户做完擦帧/切幕实验后说"我有点拿不准了" → 引导他做风格决策。
- 核心方法论（已教用户）：**风格不是"挑好看的样子"，而是"先定我是谁、给谁看"，风格自己长出来**。作品集给面试官看，硬标准=30秒读懂"这人是干嘛的、有什么本事、审美在不在线"。
- 给了两条路线对比图：A 潮流炫酷（黑底霓虹红满屏动效，冲击强但像娱乐内容）vs B 高级克制（留白少而精一个记忆点，显专业耐看）。**推荐 B 做骨架**。
- 三条理由：①给面试官看，炫酷吃掉信息 ②高级感本质是克制 ③用户内容本身够"冲"，网页做"静"才能衬出内容（动静对比）。
- 用户拍板：**暗色**（不是浅色）。
- 落地成 3 个 design token（已写进代码）：
  1. 底色 `#0a0a14`（接近黑带一点蓝，不用纯黑）
  2. 点缀色只留一个红 `#ff4d5e`（从视频里取的），其余全黑白灰
  3. 留白：字少字大，一眼看到重点
- 落地动作：pv-site 的 App.jsx 加左上角常驻 `.brand`（名字「阿意」+ 定位「游戏发行 · 内容运营」，名字旁一个小红方块点缀），index.css 加对应样式。方向 = 视频切幕做唯一记忆点 + 名字定位常驻 + 其余内容走克制排版。
