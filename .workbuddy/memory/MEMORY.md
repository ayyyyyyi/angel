# 项目：阿意求职作品集网站（vibe coding 0-1 教学项目）

## 目标与定位
- 用途：求职 / 面试展示
- 内容三类：项目案例、内容创作、实习经历
- 用户水平：纯小白，第一次做 vibe coding，需要引导式带教（循循善诱、慢慢讲、带着做）
- 【2026-08-25 方向调整·重要】用户明确：现阶段不是急着做作品集，而是想「先学会怎么搭建漂亮的网页」，等有能力了再做作品集。教学重心转向：先学「拆参考图 + CSS 皮肤 + 审美眼力」，作品集是之后的成品，不是当前目标。
- 用户确认「一点代码都不会写」，纯零基础——教学从最基础概念讲起，多用生活化比喻（传单/钥匙、乐高积木），避免术语轰炸。

## 网站结构（四块版）
1. 门面页：名字 + 一句定位 + 亮点标签 + 头图
2. 实习经历：时间线
3. 项目案例：负责什么 + 结果（强调结果，勿流水账）
4. 内容创作：视频 / 文案 / 图文

## 「石柱穿越神像」分层实验（portfolio/parallax/）
独立于门面页的另一条线：用户想验证抠图叠 z-index 能不能做出"前后穿越"的效果。
- **核心三图**：layer-bg.png（背景）+ layer-pillar.png（石柱）+ layer-angel.png（神像）
- **z-index 顺序固定**：背景 1 < 神像 2 < 石柱 3 → 前景柱廊挡神像，这是"穿越"成立的关键
- **2026-08-28 背景图换代**：用户换了 3 次背景才满意
  1. 抠走石柱神像的不完整背景 → 缺东西
  2. 完整原图（教堂）→ 叠两层一样没变化
  3. 【最终版】雪山湖面黄昏图（用户从剪贴板贴的 jpg）→ 史诗级效果
- **尺寸对齐套路**：所有图标准化到 2752×1536，PNG 用 PIL `resize((W,H), Image.LANCZOS)` 升采样
- **HTML 不加动效**：`layers-test.html` 只用 object-fit:cover + 1/2/3 数字键开关图层，方便单独看每层
- **重要经验**：用户改主意频率高（一天两次换背景），**凡是要覆盖的文件先把旧版备份为 `xxx-cutout.png` / `xxx-old.png`**，方便回滚
- 待办：用户确认效果方向后，可能加视差滚动 / 鼠标逐帧翻（pv-site 那条线的玩法移植过来）

## 【另一条线】pv-site（React+Vite 工程，portfolio/pv-site/）
用户做"PV 感滚动切换作品集"的实验，与门面页 index.html 并行。
- 演进：4张立绘图滚轮切幕 → 用户自己的15s视频切4幕+点击开始带声 → 2026-08-26 改成「滚轮逐帧翻 + 纯画面」
- 视频真实参数：24fps / 362帧 / 15.08s（不是30fps，纠正过）
- 逐帧翻方案：cv2(opencv) 抽帧 181 张（环境无 ffmpeg）→ 预加载 new Image + 单 `<img>` 换 src + wheel 累积 deltaY 阈值100翻1帧
- 关键结论（可复用）：
  ① 逐帧翻=静态图切换=天然无声音（与"带声音"冲突，二者不可兼得）
  ② 浏览器带声播放须用户点击放行：onClick 同步 unmute+play，不能靠 setState→useEffect 异步触发
  ③ 2K 大视频直接 currentTime 跳秒会卡顿不跟手，丝滑必须抽帧成图片序列
- 抽帧脚本 `extract_frames.py` 可复用（换新视频重跑）
- 待办：用户换精细 PV 后重抽帧；帧步长手感待调（当前一格一帧，181格到底）；46MB 抽帧图部署前要压缩
