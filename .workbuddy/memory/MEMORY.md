# 项目：阿意求职作品集网站（vibe coding 0-1 教学项目）

## 目标与定位
- 用途：求职 / 面试展示
- 内容三类：项目案例、内容创作、实习经历
- 用户水平：纯小白，第一次做 vibe coding，需要引导式带教（循循善诱、慢慢讲、带着做）
- 【2026-08-25 方向调整·重要】用户明确：现阶段不是急着做作品集，而是想「先学会怎么搭建漂亮的网页」，等有能力了再做作品集。教学重心转向：先学「拆参考图 + CSS 皮肤 + 审美眼力」，作品集是之后的成品，不是当前目标。
- 用户确认「一点代码都不会写」，纯零基础——教学从最基础概念讲起，多用生活化比喻（传单/钥匙、乐高积木），避免术语轰炸。

## 网站结构（四块版）
1. 门面页：名字 + 一句定位 + 亮点标签 + 头图
2. 实习经历：时间线
3. 项目案例：负责什么 + 结果（强调结果，勿流水账）
4. 内容创作：视频 / 文案 / 图文

## 「石柱穿越神像」分层实验（portfolio/parallax/）
独立于门面页的另一条线：用户想验证抠图叠 z-index 能不能做出"前后穿越"的效果。
- **核心三图**：layer-bg.png（背景）+ layer-pillar.png（石柱）+ layer-angel.png（神像）
- **z-index 顺序固定**：背景 1 < 神像 2 < 石柱 3 → 前景柱廊挡神像，这是"穿越"成立的关键
- **2026-08-28 背景图换代**：用户换了 3 次背景才满意
  1. 抠走石柱神像的不完整背景 → 缺东西
  2. 完整原图（教堂）→ 叠两层一样没变化
  3. 【最终版】雪山湖面黄昏图（用户从剪贴板贴的 jpg）→ 史诗级效果
- **尺寸对齐套路**：所有图标准化到 2752×1536，PNG 用 PIL `resize((W,H), Image.LANCZOS)` 升采样
- **HTML 不加动效**：`layers-test.html` 只用 object-fit:cover + 1/2/3 数字键开关图层，方便单独看每层
- **重要经验**：用户改主意频率高（一天两次换背景），**凡是要覆盖的文件先把旧版备份为 `xxx-cutout.png` / `xxx-old.png`**，方便回滚

### 2026-08-28·该线已从静态分层升级为完整推镜作品集
`parallax-scroll.html` 已包含完整链路：**滚轮驱动 scrub 推镜 → 贴脸 → 转场 → 占位视频画面 → 作品集卡片浮现**。
- **推镜节奏（三层各自区间）**：石柱 `start:0.00 end:0.80 ease:easeInOut`；神像 `start:0.00 end:1.00 ease:smoothstep`（后段最平缓，避免猛冲贴脸）；背景 `linear`。神像 5.5 倍砍到 **3 倍**（5.5 倍只剩脸太诡异，3 倍更对味）。
- **缓动曲线经验（可复用）**：linear=匀速机械；easeIn=结尾急刹不丝滑；easeInOut=起步踩油门中段最快结尾收住；smoothstep=两端斜率归零最平缓。
- **场景状态机**：`parallax → transition → video`，滚到底（>=0.999）自动 fade out 三层 + 切进 `video-scene` 占位画面 + 卡片浮现。
- **卡片样式（2026-08-28 改）**：仿「FALL INTO REVERIE」参考图，从原弧形 9 卡改成 **横排一字米色卡 + 衬线大字 + 编号小圆圈 + 中央卡 ▶**，5 张作品集卡（项目案例/内容创作/实习经历/数据复盘/达人招募）。参数 `flat = {spread:260, tilt:2.5, baseY:-260}`：baseY=-260 让卡片底端距屏底 115px，避让底部进度条和任务栏（原 -60 让卡片伸出屏幕被遮挡，用户反馈过）。
- **占位待补**：转场后 `video-scene` 视频素材（用户手里还没做，**不是背景层**）
- 待办：用户替换石柱抠图（透明底 PNG，2752×1536）/视频到位后填 src / 声音交互方式确定。

- 关键结论（可复用）：
  ① 逐帧翻=静态图切换=天然无声音（与"带声音"冲突，二者不可兼得）

  ③ 2K 大视频直接 currentTime 跳秒会卡顿不跟手，丝滑必须抽帧成图片序列
